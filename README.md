# REPORT_AUTOMATION
A small Python script that reads a CSV and generates a summarized report as a new CSV file.

# How To Run

1.Install Python 3 
2.Clone or download this repository 
3.Place your orders file inside a folder named project2 in the same directory as automate.py, named sample_orders.csv 
4.Run the script

# What I Learned

How to read and write CSV files in Python using the csv module, 
Using DictReader to work with rows as labeled fields, 
Aggregating totals into dictionaries , 
Formatting a multi-section report into a single CSV.
